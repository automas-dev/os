# Docs Site

This directory contains documentation site generation using mkdocs. Pages are
generated from markdown files in the project root along with design docs.

- [Project Readme](../README.md)
- [Notes & Work Planning](../notes.md)
- [Loader Notes](../loader_notes.md)
- [Design Docs](../design/)

## Usage

Setup

```sh
make setup
```

Dev server with live reload

```sh
make serve
```

Build static site

```sh
make build
```
